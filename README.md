# MealPrep Planner

MealPrep Planner is a full-stack web application for managing ingredients, recipes, weekly meal plans, nutrition calculations, cost estimates, and grocery lists.

This repository is intentionally bootstrapped in milestones.

## Current milestone

Phase 1: Project structure and architecture scaffolding only.

## Repository layout

- `frontend/` - Next.js App Router frontend (TypeScript + Tailwind CSS)
- `backend/` - FastAPI backend (Python + SQLAlchemy)
- `docs/` - Architecture notes and decision records
- `.github/` - GitHub workflows and templates
